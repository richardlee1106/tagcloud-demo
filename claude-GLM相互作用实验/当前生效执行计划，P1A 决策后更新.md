### 8.1 诊断摘要（P0.5-DiagA 结论）

| 关键发现 | 数值 | 对策 |
|---------|------|------|
| 总 cells | 67,138 | - |
| **未知标签占比** | **82.81%**（55,597 cells）| 标签传播必须放在对比学习之后 |
| 已知标签占比 | 17.19%（11,541 cells）| batch=16384 中约 2,818 个有效样本 |
| 最不均衡比 | 878:1（居住区 vs 超市）| 合并为 6 大类后降到 8.3:1，可用 Focal Loss 处理 |
| 小类极稀疏 | 超市 7 个，停车场 50 个 | 合并进大类，不能独立训练 |

**核心结论**：直接启用对比学习会失败，必须先**类别合并**再**对比学习**，标签传播放在对比学习之后（利用高质量 embedding 做传播）。

### 8.7 P0.5-FixB 状态（Range IoU 修复）

**GLM 任务**：修复 `evaluate_v26_pro.py` 中 `compute_range_query_iou` 函数

```
修复核心逻辑（替换现有 radius-based 查询）：

对于每个锚点 i：
  step1. 找物理空间 500m 内的真实近邻：
         coords_km = coords * 100（1度≈100km）
         true_set = 物理空间 KNN 中距离 < 0.5km 的点集（dynamic K）
  step2. 在 embedding 空间找最近的 len(true_set) 个点作为 pred_set
         （K 值与 true_set 大小一致，避免尺度不匹配）
  step3. IoU = |true_set ∩ pred_set| / |true_set ∪ pred_set|
  step4. 跳过 true_set 为空的锚点（孤立点）

预期：Range IoU 从 ~0.04% 提升到 20-40%（基线归正）
```
