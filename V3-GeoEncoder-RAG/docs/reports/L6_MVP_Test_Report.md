## 修复记录

### 修复1：类别提取干扰问题

**问题**：查询"华中科技大学附近500米有什么银行"时，类别被错误识别为"教育"（因为"大学"匹配到了教育类）

**解决方案**：先提取地点名，再从剩余文本中提取类别
```javascript
// 移除地点名后再匹配类别
let searchQuery = userQuery;
if (placeName) {
  searchQuery = userQuery.replace(placeName, '');
}
```

### 修复2：新增位置关键词

**新增**："边上"、"隔壁"

```javascript
const placeMatch = userQuery.match(/^(.+?)(?:附近|周边|旁边|周围|边上|隔壁)/);
```

### 修复3：新增类别

| 类别 | 关键词 |
|------|--------|
| 运动健身 | 健身房、运动、体育、游泳、羽毛球 |
| 咖啡茶饮 | 咖啡馆、咖啡、奶茶、茶饮、饮品 |
| 娱乐休闲 | 电影院、KTV、网吧、游戏、娱乐 |

### 修复4：扩充类别关键词

- **餐饮**：餐厅、饭店、美食、吃的、吃饭、餐馆、小吃

## 遗留问题

### P1：地标覆盖不足

"汉口火车站"找不到，需要：
1. 扩充POI数据库
2. 或接入高德地理编码API（需配置有效的API Key）

### P1：POI数据准确性

部分查询返回的POI与预期不符：
- 光谷广场返回的POI距离全是0米
- 武汉大学返回的是武广商圈数据

可能原因：
- POI坐标偏移
- 地理编码定位不准

### P2：性能优化

平均耗时 6-7 秒，主要耗时在 LLM 调用
