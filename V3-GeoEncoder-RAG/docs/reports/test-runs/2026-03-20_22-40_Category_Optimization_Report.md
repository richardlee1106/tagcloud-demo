## 一、问题分析

### 1. 数据库类别缺失

数据库 `pois` 表的 `category_main` 字段**不包含餐饮类**：

| 主类别 | POI数量 |
|--------|---------|
| 购物服务 | 184,550 |
| 生活服务 | 73,498 |
| 科教文化服务 | 28,584 |
| 住宿服务 | 14,363 |
| 金融保险服务 | 8,425 |
| 风景名胜 | 521 |
| **餐饮服务** | **❌ 无** |

### 2. 餐饮POI被错误标记

名称包含"餐厅"、"火锅"的POI被错误分类：

```
怪兽充电(谭鸭血老火锅光谷广场店) → 生活服务/共享设备
肯德基(武大餐厅)公共厕所 → 公共设施/公共厕所
```

### 3. 充电宝污染

大量餐厅被充电宝标签污染：

```
街电(捌零私房牛肉面馆)      → 真实店名：捌零私房牛肉面馆
来电(严记堂美食记武大店)    → 真实店名：严记堂美食记武大店
怪兽充电(奈雪の茶武商广场店) → 真实店名：奈雪の茶武商广场店
```

### 2. 充电宝名称提取

从充电宝标签中提取真实店名：

```javascript
function extractRealName(name) {
  // "怪兽充电(奈雪の茶武商广场店)" → "奈雪の茶武商广场店"
  for (const prefix of SHARED_DEVICE_PATTERNS) {
    if (name.startsWith(prefix + '(')) {
      const match = name.match(/\((.+)\)/);
      if (match) return match[1];
    }
  }
  return name;
}
```

### 3. 语义映射增强

| 用户表达 | 映射类别 |

| 好玩/景点/公园/旅游 | 景点 |
| 酒店/宾馆/住宿 | 住宿 |

## 四、已知限制

1. **数据质量问题**
   - 部分POI坐标不准确（如"武汉大学"坐标指向汉阳）
   - 建议进行数据清洗

2. **类别覆盖不全**
   - 部分餐厅命名不含餐饮关键词（如"老乡鸡"、"真功夫"）
   - 可通过品牌关键词补充

3. **LLM依赖**
   - 复杂语义仍依赖LLM解析
   - 可增加更多正则兜底
