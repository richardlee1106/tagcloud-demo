# 空间编码器分类能力探索报告

**测试时间**：2026-03-21
**测试目标**：探索空间编码器的分类能力（区域预测、方向预测、语义聚类）如何更好地利用

---

## 一、问题发现

### 1.1 OSM 餐饮 POI 缺少区域标注

| 问题 | 影响 |
|------|------|
| 49,731 条餐饮 POI 的 `region_label` 为 NULL | 无法进行区域感知检索 |
| 空间编码器的区域预测能力未利用 | 语义理解缺失 |

### 1.2 空间编码器能力未充分利用

| 能力 | 训练指标 | 当前利用 |
|------|---------|---------|
| 区域预测 | Region F1: 90.48% | ❌ 未利用 |
| 方向预测 | DirAcc: 68.41% | ❌ 未利用 |
| 语义聚类 | IntraRecall: 91.42% | ⚠️ 仅用于召回 |

---

## 二、解决方案

### 2.1 为餐饮 POI 补充区域标注

使用 `enhance_region_labels.py`，基于空间编码器预测：

```python
# 对每个餐饮 POI
region, probs = encoder.predict_region(lon, lat)
if probs[region] > 0.5:
    poi.region_label = region
```

**结果**：

| 区域类型 | 数量 | 占比 |
|---------|------|------|
| 商业类 | 31,796 | 63.9% |
| 自然类 | 9,439 | 19.0% |
| 教育类 | 169 | 0.3% |
| NULL（置信度不足） | 8,327 | 16.7% |

**覆盖率**：83.3%

## 四、关键发现

### 4.1 区域预测能力有效

- 预测准确率高（>70%）
- 可用于检索过滤和重排
- 支持"商业区的餐厅"等区域感知查询

### 4.2 语义聚类能力显著

- 同类餐厅相似度 > 97%
- 验证了 IntraRecall 91% 的训练指标
- 可用于语义相似度精排

### 4.3 当前 embedding 的局限性

- 主要编码空间位置信息
- 类别语义信息较弱（肯德基 vs 海底捞相似度也高）
- 可能因为训练时主要优化空间聚类

---

## 五、改进建议

### 5.1 短期优化

1. **区域感知检索**：在检索时，同区域 POI 加分
2. **语义相似度精排**：使用 embedding 相似度重排结果
3. **区域过滤查询**：支持"商业区的餐厅"类查询

### 5.2 中期优化

1. **重新训练编码器**：增加类别对比损失，强化语义区分
2. **多任务训练**：同时优化空间聚类和类别分类
3. **特征增强**：使用完整的 K-NN 类别分布等特征

### 5.3 长期优化

1. **方向感知检索**：支持"东边的餐厅"类查询
2. **范围预测**：支持"500米内的餐厅"类范围查询
3. **层次化多尺度**：利用 Cell 和 POI 两级编码器
