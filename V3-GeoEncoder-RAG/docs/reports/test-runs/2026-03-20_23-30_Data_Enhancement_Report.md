## 三、问题根源分析

### 3.1 为什么高德数据没有餐饮类别？

**高德POI分类体系设计**：餐饮被分散到多个大类，而非独立的"餐饮服务"类。

这源于高德的业务视角：POI按照**功能属性**而非**消费场景**分类。

### 3.2 充电宝污染来源

高德将共享充电宝设备作为**独立POI**收录，类别为"生活服务/共享设备"。

设备安装在餐厅、咖啡店等场所，导致名称格式为 `品牌(场所名)`。
