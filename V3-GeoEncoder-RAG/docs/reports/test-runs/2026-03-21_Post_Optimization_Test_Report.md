## 七、问题诊断深入

### 7.1 景点数据验证

```
风景名胜大类: 521 条
- 风景名胜景点: 274 条
- 公园广场: 149 条
- 风景名胜: 98 条
```

数据存在！问题是意图解析把"武汉市有哪些景点推荐"错误解析为 placeName="武汉大学"。

### 7.2 FAISS 性能问题诊断

| 检索方式 | 耗时 | 原因 |
|---------|------|------|
| PostGIS 空间查询 | 116ms | 使用空间索引 |
| JS "FAISS" 实现 | 521ms | 遍历所有 615K POI |

**根本原因**：`faissIndex.js` 没有使用真正的 FAISS 库，只是用 JS 数组遍历所有 POI 计算 Haversine 距离。

**代码问题**（faissIndex.js:472）：
```javascript
for (let i = 0; i < n; i++) {  // 遍历所有 615K POI
    const dist = haversineDistance(anchor, coords[i]);
    if (dist <= radius) { ... }
}
```

### 7.3 意图解析问题

| 查询 | 错误解析 | 正确解析 |
|------|---------|---------|
| "武汉市有哪些景点推荐" | placeName="武汉大学" | placeName=null |
| "一日游推荐" | placeName="武汉大学" | placeName=null |

**原因**：小模型没有区分"城市级查询"和"地点级查询"。
