# 贡献者行为准则

## 我们的承诺

我们致力于为所有人提供一个受欢迎和激励的社区。我们承诺，无论年龄、体型、种姓、残疾、种族、性别特征、性别认同和表达、经验水平、教育程度、社会经济地位、国籍、个人外貌、种族、宗教或性认同和取向，参与我们社区都是无骚扰的体验。

我们致力于提供一个积极、包容和安全的环境，让所有贡献者感到被尊重、重视和有能力贡献最佳工作。

## 我们的标准

有助于创造积极环境的行为示例包括：

### 尊重他人
- 使用热情和包容的语言
- 尊重不同的观点、意见和经历
- 优雅地接受建设性批评
- 尊重文化和语言差异
- 认可和庆祝不同的背景

### 协作
- 共同努力解决冲突
- 给予信任并认可他人的贡献
- 帮助他人学习和成长
- 分享知识并提出问题
- 支持社区成员

### 专业
- 保持讨论聚焦和高效
- 避免贬低或侮辱性言论
- 在 issues 和讨论中保持主题
- 使用清晰和尊重的沟通
- 假设他人消息中的善意

### 包容
- 欢迎新贡献者
- 帮助新加入项目的人上手
- 提供建设性反馈
- 纳入不同观点的人
- 为安静的声音创造空间

## 不可接受的行为

以下行为被视为骚扰，在我们社区中是不可接受的：

### 骚扰和歧视
- 与性别、性别认同和表达、性取向、残疾、精神疾病、神经(a)典型性、体型、外表、年龄、种族或宗教相关的攻击性评论
- 关于个人生活方式选择和实践的不受欢迎评论
- 故意用错代词或使用"死"名或被拒绝的名字
- 过度的或不相关的主题性图片或行为
- 未经同意的身体接触或在要求停止后继续身体接触

### 滥用行为
- 针对他人的暴力威胁或暴力语言
- 教唆对任何人的暴力或暴力语言
- 故意恐吓
- 跟踪或尾随
- 通过重复联系进行骚扰
- 任何其他可合理认为不适当的行为

### 网络骚扰
- 持续打断在线讨论
- 发布他人的私人信息（人肉搜索）
- 不受欢迎的性关注或挑逗
- 挑衅或故意破坏
- 垃圾邮件或重复广告
- 传播虚假信息或故意误导的信息

### 报复
- 对报告违规行为的人采取报复行动
- 因为某人报告了不可接受行为而对他不公平
- 威胁要举报某人作为报复

## 范围

本行为准则适用于：
- 所有社区空间（GitHub issues、pull requests、discussions 等）
- 项目仓库和文档
- 由项目组织或代表的活动和聚会
- 个人代表项目或社区的公共空间
- 与项目业务相关的私人通信

行为准则适用于所有项目空间，当个人在公共空间代表项目或社区时也适用。代表项目或社区的示例包括使用官方项目电子邮件地址、通过官方社交媒体账户发帖，或作为在线或离线活动的指定代表行事。

## 执行

社区负责人负责澄清和执行可接受行为的标准，并将采取适当和公平的纠正措施来应对任何被认为不适当、威胁性、攻击性或有害的行为。

### 报告违规行为

如果你经历或目睹了不可接受的行为，或有任何其他顾虑，请通过以下方式报告：

1. **电子邮件**：联系项目维护者
2. **GitHub Issues**：私人报告功能（如果在你的 GitHub 设置中可用）
3. **直接消息**：直接联系项目维护者

请提供：
- 你的联系信息
- 涉及人员的姓名（如果你愿意分享）
- 事件描述
- 上下文和任何相关链接
- 事件如何影响你

**所有报告都将保密。**

### 调查和回应

社区负责人将：
- 及时公平地审查和调查所有投诉
- 对报告者保密
- 向报告者回应其报告的状态
- 根据调查结果采取适当行动

可能的行动包括：
- 私下警告或指导
- 公开道歉（如果违规者同意）
- 暂时或永久从社区空间移除
- 失去贡献者特权
- 如有需要升级到 GitHub 或其他平台

### 上诉流程

如果你认为决定有误，你可以通过以下方式上诉：
1. 提供新信息或上下文
2. 请求多名维护者审查
3. 在初步决定后 30 天内跟进

## 尊重分歧的准则

分歧在技术社区中是自然的。以下是尊重分歧的方式：

### 应该做
- 关注观点而不是人
- 提出澄清性问题
- 承认对立观点中的有效点
- 使用"我"的陈述（"我不同意，因为..."）
- 引用来源和证据
- 感谢他人的观点

### 不应该做
- 进行人身攻击
- 使用轻蔑语言（"这很愚蠢"）
- 假设恶意
- 提出不相关的过去冲突
- 提高语调或变得敌对
- 故意歪曲他人观点

### 尊重分歧的示例
```
❌ 不好："这是个愚蠢的想法，你显然不理解这个项目。"

✅ 好："我理解你的观点，但我担心这种方法可能无法很好地扩展大型项目。你考虑过这个基准测试中显示的性能影响吗？我很想听听你对此的看法。"
```

## 建立桥梁

我们相信对话与和解的力量：

- 如果有人指出你的行为，请倾听和反思
- 如果你造成了伤害，愿意道歉
- 支持他人在学习和成长
- 认识到人们会犯错
- 关注解决方案而不是指责
- 在保持问责的同时假设善意

## 遵循本准则的好处

通过维护一个尊重和包容的社区，我们：
- 吸引具有不同观点的多元化贡献者
- 通过协作创造更好的解决方案
- 建立更牢固的关系
- 使项目对新来者更受欢迎
- 产生更高质量的文档和示例
- 培养学习和成长的文化

## 特别考虑

### 对于维护者
- 在遵守本准则方面以身作则
- 及时回应报告
- 对决定保持透明
- 公平地帮助解决冲突
- 为所有人创造安全环境

### 对于贡献者
- 假设维护者和其他贡献者的善意
- 提供建设性反馈
- 支持新来者
- 帮助执行社区标准
- 对社区文化负责

### 对于每个人
- 记住每条消息背后都有一个人
- 如果感到沮丧，请休息一下
- 如果需要支持，请联系社区负责人
- 帮助创建你想要参与的社区
