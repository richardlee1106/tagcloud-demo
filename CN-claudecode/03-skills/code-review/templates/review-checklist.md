# 代码审查清单

## 安全清单
- [ ] 无硬编码的凭证或密钥
- [ ] 所有用户输入都有验证
- [ ] SQL 注入防护（使用参数化查询）
- [ ] 状态变更操作有 CSRF 防护
- [ ] XSS 防护，正确转义
- [ ] 受保护端点有认证检查
- [ ] 资源有授权检查
- [ ] 安全密码哈希（bcrypt、argon2）
- [ ] 日志中无敏感数据
- [ ] 强制使用 HTTPS

## 性能清单
- [ ] 无 N+1 查询
- [ ] 合理使用索引
- [ ] 在有益处实施缓存
- [ ] 主线程上无阻塞操作
- [ ] Async/await 使用正确
- [ ] 大数据集有分页
- [ ] 数据库连接池化
- [ ] 正则表达式已优化
- [ ] 无不必要的对象创建
- [ ] 防止内存泄漏

## 质量清单
- [ ] 函数小于 50 行
- [ ] 变量命名清晰
- [ ] 无重复代码
- [ ] 错误处理得当
- [ ] 注释解释"为什么"，而不是"是什么"
- [ ] 生产环境无 console.log
- [ ] 有类型检查（TypeScript/JSDoc）
- [ ] 遵循 SOLID 原则
- [ ] 设计模式应用正确
- [ ] 代码自文档化

## 测试清单
- [ ] 已编写单元测试
- [ ] 覆盖边界情况
- [ ] 测试了错误场景
- [ ] 有集成测试
- [ ] 覆盖率 > 80%
- [ ] 无不稳定测试
- [ ] 模拟外部依赖
- [ ] 测试名称清晰
